# Старые тесты неактивного legacy-клиента

`client-courses.test.mjs` и `client-retry.test.mjs` запускали старый `public/app.mjs` в самодельном «мини-браузере».
Активный клиент теперь React (`client/src`), а эти тесты заменены настоящими тестами интерфейса в `tests/ui/`.
Файлы оставлены только как справка (удалять без разрешения нельзя) и **не входят** в `npm test` (его маска — `tests/*.test.mjs`).
Запустить вручную, если очень нужно: `node --test tests/legacy/*.test.mjs`.
